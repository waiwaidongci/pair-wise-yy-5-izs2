# 手工织锦纹样排版台 · 张力巡查与上机放行

直接打开 `index.html` 使用。

## 画布功能

- 经纬网格绘制（单点/十字/小菱形纹样块，拖动连填）
- 色线用量统计、重复单元预览、断线行风险提示
- 撤销 / 重做、本地保存、导出 JSON

## 张力巡查与上机放行

按经区登记经纱张力，替代换班口头交接：

- **登记**：按经区记录张力读数、环境湿度、巡查人、处理说明；同一经区重复提交时只保留本次实测为现行值，先前读数全部留在该区履历。
- **判定**：读数偏离该区基准 **8%**，或与相邻区相差 **超过 3 档**（每 5 cN 为一档），该区转「待复检」；只要有待复检或未实测经区，整幅图案不能生成上机许可。
- **复检**：复核须换人（系统按姓名拦截原巡查人），调整张力并重新实测合格后才解除待复检。
- **放行**：全幅合格后由放行人签发上机许可（编号 `SJ-日期-时间`），存档含当时机数、经区划分、基准、各区读数与巡查记录。
- **参数变更**：改动机数、经区划分、各区基准（或经向列数）会让现行许可立即失效，并按新参数复算；经区重划后须按新分区重新实测（履历保留）。

## 文件划分

| 文件 | 职责 |
|---|---|
| `inspection.js` | 巡查判定：登记/履历、8% 偏离与相邻档差判定、换人复检、参数复算 |
| `release.js` | 放行档案：许可签发、参数指纹与失效判定 |
| `app.js` | 页面动作：画布编辑、统计、撤销重做、保存、导出及巡查/放行交互 |
