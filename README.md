# 手工织锦纹样排版台

直接打开`index.html`使用。支持网格绘制、色线统计、撤销重做、本地保存和导出JSON。

## 张力巡查与上机放行

- 按经区登记张力读数、环境湿度、巡查人和处理说明；同一经区重复提交只保留本次实测，先前值留在读数履历。
- 读数偏离该区基准 8%，或与相邻区相差超过三档（每档 2 cN）时，该区转待复检，整幅图案不能生成上机许可。
- 复核须换人登记，调整张力并重测合格后才放行。
- 改动机数、经区划分或基准会使已发许可失效，并按新参数复算。

## 文件结构

- `js/inspection.js`：巡查判定（读数登记、履历、偏差与邻档判定、换人复核校验）
- `js/release.js`：放行档案（许可签发、失效判定、档案持久化）
- `js/app.js`：页面动作（画布、统计、撤销重做、保存导出与巡查界面接线）
